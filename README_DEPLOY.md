# SK Interiors — Pro Static Website

This website is intentionally built as plain HTML + CSS + JavaScript so it can be hosted for free as a static site.

## Recommended free hosting: Cloudflare Pages

Cloudflare currently supports Direct Upload for prebuilt static assets. In the Cloudflare dashboard:

1. Open **Workers & Pages**.
2. Choose **Create application** / **Get started**.
3. Choose **Drag and drop your files** (Direct Upload).
4. Project name: `sk-interiors-demo` (or another available name).
5. Upload the **contents of this folder** or upload the ZIP if the UI accepts ZIP upload.
6. Deploy.
7. Cloudflare will give you a URL similar to `https://sk-interiors-demo.pages.dev`.

No database, server, paid form service, or build command is required.
